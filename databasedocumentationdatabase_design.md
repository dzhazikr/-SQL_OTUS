# Дизайн базы данных для платформы анализа продаж

## Сущности и связи

### Основные таблицы:
1. `customers` - Клиенты
2. `products` - Товары
3. `sales` - Продажи (факты)
4. `categories` - Категории товаров
5. `regions` - Регионы
6. `employees` - Сотрудники
7. `customer_segments` - Сегменты клиентов

## Схема отношений:
- Один клиент → Много продаж
- Один продукт → Много продаж
- Один регион → Много клиентов
- Одна категория → Много продуктов
- Один сегмент → Много клиентов
- Один сотрудник → Много продаж
