# -SQL_OTUS
SQL для разработчиков и аналитиков

База данных для комплексного анализа продаж, включая сегментацию клиентов, анализ динамики продаж и прогнозирование на основе исторических данных.

Функциональность

1. Управление данными о продажах
   - Регистрация продаж
   - Управление клиентами и продуктами
   - Отслеживание запасов

2. Аналитика и отчетность
   - RFM-анализ клиентов
   - ABC-анализ товаров
   - Анализ динамики продаж
   - Анализ эффективности сотрудников

3. Прогнозирование
   - Прогноз продаж на основе скользящего среднего
   - Анализ сезонности
   - Прогнозирование спроса

4. Установка и запуск

- Установите PostgreSQL
- Выполните скрипты в порядке:
```bash
psql -f database/sql_scripts/01_create_tables.sql
psql -f database/sql_scripts/02_insert_data.sql
psql -f database/sql_scripts/03_functions.sql
psql -f database/sql_scripts/04_procedures.sql
psql -f database/sql_scripts/05_optimization.sql


Примеры аналитических запросов находятся в папке reports.
